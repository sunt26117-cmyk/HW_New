# AutoHW Core Phase 12 · EMC / BCI 引擎化

本阶段把旧版已有的 BCI 工程入口接回新架构，不把旧版按域名 switch 的方案文案或多套状态管理搬回 Core。

## 新增确定性 Pattern

- `EMC.P001`：BCI 功能抗扰异常。必须具备注入电流、敏感频点、功能结果标记；发现可重复功能异常时触发 `High`。这里不自动制造 VETO，因为项目安全放行门禁需要工程师/项目规范定义。
- `EMC.C001`：BCI 试验可追溯性检查。检查扫频起止、代表性注入电流、实际线束长度是否完整；它是 `CHECKLIST`，不计入风险触发统计。

## 输入与证据

沿用旧版已有字段：BCI 注入电流、敏感频点、电流采样误差、恢复时间、线束长度、受扰节点电压、共模电流，并新增结构化测试结果标记和试验覆盖边界。所有数值进入统一 `Quantity`/`EvidenceKind`。

## 边界

本阶段不虚构任何标准限值；测试等级、功能放行等级、检波方式等仍从项目 EMC 规范/试验计划进入证据层。真正现场数据进入 `fixtures/gold/` 后，才能成为 Gold Case。
